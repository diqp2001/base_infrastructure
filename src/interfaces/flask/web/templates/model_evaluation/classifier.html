Classifier model evaluation

Does the model identify which stocks end in the better or worse future-performance classes? Evaluated as a classifier, independent of any trading strategy. True class = the class the stock realised after the prediction date (the model's own label rule); predicted class = argmax of its class probabilities at the date; probability quintile = the stocks of ONE date ranked by one class probability, Q1 lowest .. Q5 highest — neither the true nor the predicted class.
